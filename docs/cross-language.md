# C Bindings

The library exposes a C API via generated headers in `bindings/c/github_mock_api/` and a native library `libgithub_mock_api_ffi` (`.so`, `.dylib`, `.a`, or `.dll`).

---

## Getting the library

The C headers are generated at build time and the native library is produced by the `github-mock-api-ffi` crate. Build both with:

```bash
cargo build -p github-mock-api-ffi --release
```

Output:

| Artifact | Location |
|----------|----------|
| Library | `target/release/libgithub_mock_api_ffi.{so,dylib,a,dll}` |
| Headers | `bindings/c/github_mock_api/` (generated by `ffi/build.rs`) |

For a debug build, omit `--release`; the library will be in `target/debug/`.

---

## API Reference

```c
#include "github_mock_api/MockServer.h"
```

| Function | Description |
|----------|-------------|
| `MockServer_start_result MockServer_start(void);` | Start on `127.0.0.1` with a random port |
| `MockServer_start_on_result MockServer_start_on(const char *host, uint16_t port);` | Start on a host and port (`0` = random) |
| `void MockServer_uri(const MockServer *self, DiplomatWrite *write);` | Write base URI into a `DiplomatWrite` buffer |
| `MockServer_stop_result MockServer_stop(MockServer *self);` | Stop and wait for shutdown |
| `void MockServer_destroy(MockServer *self);` | Free the handle |

**Strings** are returned via Diplomat's `DiplomatWrite` pattern — write into a writable buffer, then read the bytes back:

```c
#include "github_mock_api/diplomat_runtime.h"

DiplomatWrite *w = diplomat_buffer_write_create(64);
MockServer_uri(server, w);
const char *bytes = (const char *)diplomat_buffer_write_get_bytes(w);
size_t len = diplomat_buffer_write_len(w);
// use bytes[0..len]
diplomat_buffer_write_destroy(w);
```

**Errors** are returned in result structs. Every fallible function returns a struct with `is_ok`, `ok`, and `err` fields:

```c
MockServer_start_result result = MockServer_start();
if (result.is_ok) {
    MockServer *server = result.ok;
    // ...
} else {
    MockServerError err = result.err;
    // handle error
}
```

## Example

```bash
cargo build -p github-mock-api-ffi --release

cc -std=c11 -I bindings/c my_program.c \
  -L target/release -lgithub_mock_api_ffi \
  -o my_program -Wl,-rpath,"$PWD/target/release" -pthread

./my_program
```

```c
#include "github_mock_api/MockServer.h"
#include "github_mock_api/diplomat_runtime.h"
#include <stdio.h>

int main(void) {
    MockServer_start_result started = MockServer_start();
    if (!started.is_ok) {
        fprintf(stderr, "failed to start server\n");
        return 1;
    }

    MockServer *server = started.ok;

    DiplomatWrite *uri = diplomat_buffer_write_create(64);
    MockServer_uri(server, uri);
    printf("URI: %s\n", (const char *)diplomat_buffer_write_get_bytes(uri));
    diplomat_buffer_write_destroy(uri);

    MockServer_stop_result stopped = MockServer_stop(server);
    MockServer_destroy(server);
    return stopped.is_ok ? 0 : 1;
}
```
